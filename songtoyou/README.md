# SongToYou · 한국인 대상 AI 맞춤 노래 선물 (시연 프런트엔드)

## 핵심 컨셉
릴스·스레드 영상으로 이미 후킹된 방문자가 바로 행동하도록 설계했습니다.
**질문에 답하기(무료) → 완성곡 전곡 감상(무료) → 마음에 들면 결제 / 아니면 결제 없이 종료**

## 구성
- `index.html` 히어로 · 리액션 · 이용 방법 · 후기(예시) · 미리듣기 · 특별한 순간 · MR 옵션 · 요금 · FAQ · 하단 고정 CTA(모바일)
- `app.js` 8단계 질문 → 제작(시연) → 결과 감상 → 결정(결제/수정/종료) → 결제(시연) → 선물 페이지 미리보기
- `terms.html` `privacy.html` `refund.html` 한국 법령 기준 약관 초안, `order-status.html` 주문 조회(시연)
- 참고 사이트의 구조(섹션 순서·주문 흐름)만 따르고 문구·약관은 모두 새로 작성했습니다.

## 실행
`cd songtoyou && python3 -m http.server 8080`

## 출시 전 필수
1. 실제 사업자 정보·통신판매업 신고, 약관/방침/환불 문서의 [대괄호] 채우기 및 법률 검토
2. 서버: 제작 API(가사·음악), 결제대행(카카오페이·토스·네이버페이), 알림톡/문자, 주문 DB, 부정사용(무료 제작 남용) 방지·전곡 스트리밍 보호
3. 후기·리액션은 본인 동의를 받은 실제 자료만 게재. 수치(리뷰 수, 평점 등)는 실제 데이터가 생기기 전까지 표기하지 않음
4. AI 생성곡의 상업적 이용·저작권 조건 확인 (결혼식·영상 이용 범위 확정)
